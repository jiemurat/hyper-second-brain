# When the user is stuck

This reference holds the help with creative or analytical work that is stuck. The ways to find are in `finding.md`; this file names them and does not repeat them.

## Contents
- When
- The steps

## When

Use this when the user says they are stuck: a text that will not come, a proposal that will not come together, a decision that will not settle. A block usually means too little raw material, not too little talent.

## The steps

1. Name the output the user is working toward and the point of view it advances; ask the user when either is unclear.
2. List what the vault holds toward it, by kind: examples, stories, statistics, diagrams, analogies, quotes, photos, and notes of conversations, each with its title and folder. Search the project's folder first, then its area, Resources, and Archives (`finding.md` → "The four ways to find").
3. Name the kinds that are thin or missing, and for each one propose what to gather and where it could come from: the user's older notes, people to talk to, or research outside the vault, which you start only on the user's yes.
4. Put the block as missing material: say what the work needs next, not what the user lacks.

Done when the user has the list of what the vault holds toward the work, by kind, and a proposal for each gap.
