# Preparing for a meeting

This reference holds the preparation for a meeting, a conversation, or a decision. The ways to find are in `finding.md`; this file names them and does not repeat them.

## Contents
- When
- The steps
- After the meeting

## When

Use this when the user asks for help preparing for a meeting, a conversation, or a decision.

## The steps

1. Learn the occasion and the project or topic behind it; ask the user when either is unclear.
2. Find the notes that bear on it (`finding.md` → "The four ways to find"): the project's folder first, then its area, Resources, and Archives. Read what you find.
3. Sort the notes into three groups: critical (they decide the outcome, or the user must raise them), possibly relevant, and set aside.
4. Give the user, in the chat, an agenda built from the critical notes, each item naming the note it comes from by its title and folder, and a list of the possibly relevant notes with their titles and folders. Leave the set-aside notes out. Save the agenda as a note only when the user asks.

Done when every agenda item names its source note, and the list gives the title and folder of each remaining relevant note.

## After the meeting

When the user reports what came out of the meeting (decisions, new ideas, objections, questions), switch to the `hsb-place-an-item` skill: open its `SKILL.md` in the folder next to this skill's folder, and follow its steps with the user's report as the item to place. This skill itself writes nothing about the outcome.
